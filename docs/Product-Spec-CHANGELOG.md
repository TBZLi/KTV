# 声域友 - 产品需求变更记录

## [1.4.0] - 2026-05-12

### 新增
- 系统设置 - 节假日动态定价：管理员手动添加节假日日期范围（日期范围选择器），按包厢类型设置倍率（VIP 默认 1.5x、中 1.3x、小 1.2x）
- 系统设置 - 操作日志：记录所有增删改操作（订单、余额、用户、歌曲、房间、设置、登录），嵌在系统设置页面，分页展示，支持按类型/日期/操作人筛选，所有管理员可查看
- 系统设置 - 敏感操作二次验证细化：从开关改为勾选制，可独立配置删除订单、余额调整、禁用/启用用户、批量上下架歌曲、修改系统设置、修改管理员账号

### 修改
- 系统设置：配置区块由四个调整为六个（管理员账号、基本信息、定价设置、安全设置、操作日志）
- 系统设置 - 节假日动态定价：从占位开关改为完整的日期管理 + 倍率配置
- 系统设置 - 敏感操作二次验证：从单开关改为按操作类型独立勾选

## [1.3.0] - 2026-05-12

### 新增
- 系统设置：新增"管理员账号"配置区块，管理员账号在系统设置中单独管理，不在账户管理列表中展示
- 订单管理：新增"恢复"操作，仅已取消订单支持恢复，恢复后订单状态变回进行中，房间重新绑定，用户余额重新扣款
- 订单管理：新增搜索功能，下拉菜单切换搜索方式（订单号 / 用户名 / 包厢号），模糊匹配
- 账户管理：禁用用户时增加确认提示，如有进行中订单则显示"该用户有 X 个进行中订单，禁用后将全部取消并退款"

### 修改
- 账户管理：管理员账号不可禁用，禁用操作仅对普通用户生效
- 账户管理：禁用用户后，该用户所有进行中订单自动标记为"已取消"并退款至余额
- 账户管理：被禁用用户不出现在新建订单的用户下拉选项中
- 订单管理：创建时间精确到秒级，使用北京时间（UTC+8）
- 系统设置：配置区块由三个调整为四个（管理员账号、基本信息、定价设置、安全设置）

## [1.2.0] - 2026-05-12

### 新增
- 仪表盘总收入增加时间维度筛选：今日 / 本周 / 本月 / 自定义日期范围
- 订单管理：终态订单（已完成/已取消/已退款）支持删除操作（软删除，需二级密码验证）
- 房间管理：操作列增加状态切换按钮（使用中→结束会话、打扫中→变空闲）
- 账户管理：余额调整支持正数（充值）和负数（扣款），需二级密码验证
- 安全性：敏感操作（删除订单、余额调整）增加二级密码验证机制

### 修改
- 管理端所有列表展示：ID 替换为人类可读名称（包厢号、用户名），新建订单表单改为下拉选择
- 账户管理："充值"操作更名为"调整余额"
- 仪表盘总收入计算规则：SUM(amount) WHERE status IN ('in_progress', 'completed')，排除已退款/已取消/已删除

## [1.1.0] - 2026-05-12

### 修改
- 房间管理：新建订单时订单号自动绑定到房间的"当前订单"字段，结束/退款/取消/完成后自动清空
- 订单管理：增加"完成"和"取消"操作按钮，完善订单状态流转闭环
- 订单管理：新建订单时"金额"字段改为"使用时长（小时）"，金额按 小时数 × 单价基数 自动计算
- 订单管理：增加"自定义金额"二级选项，勾选后可直接输入金额，适用于包场、折扣等特殊情况
- 订单退款/取消：操作后房间状态统一处理（退款/取消→空闲，完成→打扫中）

## [1.0.0] - 2026-05-02

### 新增
- 项目概述：产品定位、目标、范围
- 目标用户定义：管理端用户（运营人员）、Web 端用户（顾客）
- 管理端 6 个功能模块完整需求：仪表盘、房间管理、歌曲管理、订单管理、账户管理、系统设置
- Web 端 6 个功能模块完整需求：登录、探索歌曲、热门榜单、我的收藏、当前房间、底部播放器栏
- 功能优先级总览：P0（6项）、P1（4项）、P2（2项）
- AI 增强功能建议：智能歌曲推荐、智能搜索补全、营业数据洞察
- 非功能性需求：性能、兼容性、安全性、可用性、代码质量
- 技术栈确认：Vue 3 + ASP.NET Core 8.0 + SQL Server
- 组员分工建议
